# Athijeevana

Website for Athijeevana — a community mental-health initiative by Jeevani Institute of Mind Care, Westfort, Thrissur, Kerala.

Built with React, Vite, TypeScript and Tailwind CSS. Deployed as a static site.

## Development

```bash
bun install
bun run dev
```

## Build

```bash
bun run build
```
